# Neon Draw

A plain HTML/CSS/JS drawing toy: glowing neon strokes that slowly fade away. Pick a colour, turn on mirror
mode (⇋), or clear (✕).

- **On desktop:** open `index.html` in a browser.

**Tests in Olive:** a **plain web page split across folders**: `css/style.css`, two scripts in `js/` that must
load in order (`colors.js` before `draw.js`), and an SVG in `img/`. The app folds all of these into one page and
it runs straight away, without the runner. Drawing should work with your finger.
